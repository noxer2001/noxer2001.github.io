Política de Privacidade

Segunda Mente · atualizada em 5 de novembro de 2026

Quem usa

A Segunda Mente é um aplicativo de uso pessoal. É usado apenas pelo seu dono, nas contas Google dele, e não é oferecido a outras pessoas.

Quais dados acessa

  • Gmail (leitura): conteúdo e metadados das mensagens, para busca e resumos.
  • Google Agenda (leitura): eventos, para responder sobre compromissos.
  • Gmail (envio) e Agenda (criação de eventos): usados somente quando o dono aprova manualmente cada ação.
  • Endereço de e-mail da conta: para confirmar que a conta autorizada é a correta.

Onde os dados ficam

Todos os dados ficam armazenados localmente no computador do dono, num banco de dados próprio. Não há servidor na nuvem do aplicativo.

Compartilhamento

Os dados não são vendidos nem compartilhados com terceiros e não são usados para publicidade. Trechos relevantes podem ser enviados ao assistente de IA (Claude, da Anthropic) apenas para responder perguntas feitas pelo próprio dono.

Uso das APIs do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Remoção

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Apagar a pasta de dados do aplicativo remove todas as informações armazenadas.
